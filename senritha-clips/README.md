# Senritha's Random Clips
อัดหน้าจอระยะยาวได้ 2 โหมด
- **สุ่มคลิปสั้น:** สุ่มเก็บคลิปสั้นเป็นช่วง ๆ เช่น รัน 1 ชั่วโมง อัดคลิปละ 15 วินาที เว้นคูลดาวน์ 3–10 นาที
- **อัดยาวต่อเนื่อง:** อัดตลอดทั้งเซสชันเป็นไฟล์เดียว หรือแบ่งไฟล์ทุก X นาที (ต่อไฟล์แบบไม่มีช่องว่าง)

แต่ละไฟล์เปิดได้ทันที และเลือกได้ว่าจะเก็บไฟล์ไหน

ใช้บน PC ด้วย Chrome หรือ Edge (Firefox ใช้ได้ แต่ไม่มีโหมดบันทึกลงโฟลเดอร์) ต้องเปิดผ่าน https หรือ localhost

## ตั้งค่าได้
- **โหมด:** สุ่มคลิปสั้น หรืออัดยาวต่อเนื่อง
- **เซสชัน:** ระยะเวลารัน (หรือไม่จำกัด), แบ่งไฟล์ทุก X (โหมดอัดยาว), จำนวนคลิปสูงสุด, เวลารอก่อนคลิปแรก (สุ่มในช่วง)
- **คลิปและการสุ่ม:** ความยาวคลิป (ค่าคงที่หรือสุ่มในช่วง), คูลดาวน์ต่ำสุดถึงสูงสุด, รูปแบบ *สุ่มอิสระ* หรือ *กระจายทั่วเวลา*, ความยาวเมื่อกด “อัดตอนนี้”
- **คุณภาพวิดีโอ:** ต่ำ (720p 15fps) / กลาง (1080p 30fps) / สูง (1440p 30fps) / สูงสุด (ตามจอ 60fps) / กำหนดเอง (ความละเอียด, เฟรมเรต, บิตเรต) แสดงขนาดไฟล์ต่อนาที; MP4 หรือ WebM; แหล่งที่จะแนะนำ
- **เสียง:** เสียงระบบ, ไมโครโฟน (เลือกตัวได้) และระดับเสียงของแต่ละแหล่ง
- **บันทึกไฟล์:** *ตรวจทีหลัง* (ค่าเริ่มต้น), ดาวน์โหลดทันที หรือบันทึกลงโฟลเดอร์ที่เลือกทันที (เขียนลงดิสก์ระหว่างอัด เหมาะกับอัดยาว); ตั้งชื่อขึ้นต้นไฟล์ได้
- **อื่น ๆ:** โหมดเซอร์ไพรส์ (ซ่อนตาราง), พรีวิว, แจ้งเตือน, เสียงบี๊ป, พรีเซ็ตสำเร็จรูปและบันทึกพรีเซ็ตของตัวเอง

ระหว่างรัน: อัดตอนนี้ (`R`), พัก/ทำต่อ (`P`), ข้ามคลิปถัดไป, สุ่มเวลาที่เหลือใหม่, หยุด (โหมดอัดยาว: พักแล้วอัดต่อในไฟล์เดิม)

## ตรวจทีหลัง (เลือกคลิปที่จะเก็บ)
คลิปพักไว้ในหน้า ยังไม่เซฟ กด **เก็บ** / **ทิ้ง** ที่แต่ละคลิป หรือเปิดเล่นแล้วไล่ดูทีละคลิป (`←` `→`, `K` = เก็บ, `X` = ทิ้ง แล้วข้ามไปคลิปถัดไป) กรองดู ทั้งหมด / ยังไม่ตรวจ / เก็บ / ทิ้ง แล้วกด **เซฟที่เก็บ** ไปที่ Downloads หรือโฟลเดอร์ที่เลือก และ **ลบที่ทิ้ง** เพื่อคืนหน่วยความจำ

## ทำงานอย่างไร
- แชร์หน้าจอครั้งเดียวตอนกดเริ่ม (`getDisplayMedia`) แต่ละคลิปใช้ `MediaRecorder` ตัวใหม่ ไฟล์จึงสมบูรณ์ในตัว
- ตารางเวลาสุ่มไว้ล่วงหน้าและแสดงบนไทม์ไลน์ เวลาที่พักไม่นับ
- ตัวจับเวลาอยู่ใน Web Worker เพื่อให้ตรงเวลาแม้แท็บอยู่เบื้องหลัง
- ไม่มีอะไรถูกส่งออกจากเครื่อง ค่าตั้งและพรีเซ็ตเก็บใน `localStorage`, โฟลเดอร์ที่เลือกเก็บใน IndexedDB

## ข้อควรรู้
- อย่าให้คอมพิวเตอร์เข้าโหมด sleep ระหว่างรัน (แอปขอ wake lock ให้เฉพาะตอนเปิดหน้านี้อยู่)
- เสียงระบบ: Windows ได้ทั้งจอและแท็บ, macOS ได้เฉพาะแท็บ ต้องติ๊ก “แชร์เสียง” ตอนเลือกจอ
- กด “หยุดแชร์” ของเบราว์เซอร์ = จบเซสชัน

## Files
- `index.html`, `style.css`: หน้าแอป
- `app.js`: ตั้งค่า, ตัวสุ่มตารางเวลา, ตัวอัด, รายการคลิป
