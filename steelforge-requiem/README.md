# Steelforge Requiem
เกมรถถังมุมมองจากด้านบน (v5) เล่นบนเบราว์เซอร์ ไฟล์เดียว ไม่ต้องติดตั้ง

- **โหมด:** Frontline (ยึดโซน 7 จุด), ดวล, ยึดจุด / เดธแมตช์, Infinity (เวฟไม่จำกัด + เลือกบัฟ)
- **โรงประกอบ:** ตัวถัง, ปืน, ออโตโหลด, เกราะ, ERA, APS, ควัน, เรดาร์, จูน, ลูกเรือ, กระสุน, สกิน
- **เล่นได้ทั้ง PC และมือถือ:** คีย์บอร์ด + เมาส์ (ปรับปุ่มเองได้) หรือจอยคู่ + ปุ่มยิง
- **ออโต้แคนนอน:** ยิงรัวทุกรุ่น (กดค้าง) มีแม็กจำกัด หมดแล้วเปลี่ยนแม็ก · IFV 30/45/57/75mm = 16/12/10/8 นัด · อาวุธรองรถถัง 20/30/45mm = 30/20/12 นัด
- **ควัน:** พก 12 / 24 / 36 ลูก (Gen1/2/3)
- **อากาศยานใน Frontline (สัดส่วนจริง):** ฝ่ายเรา A-10C · F-35A · AH-64E Apache — ฝ่ายศัตรู Su-25 · Su-57 · Ka-52 · มี Dogfight (ขีปนาวุธ แฟลร์ ปืนอากาศ ถูกยิงตกได้) และเครื่องขับไล่ขึ้นสกัด
- **เสียง (v3):** สังเคราะห์ทั้งหมด · แต่ละเครื่องบินมีเสียงเฉพาะ (GAU-8 "บรรรต", ใบพัดร่วมแกน Ka-52 ฯลฯ) · Doppler · flyby · sonic boom เมื่อเครื่องบินเหนือเสียงบินผ่าน · จำกัดจำนวนเสียงพร้อมกัน (เสียงไม่หายเมื่อซ้อนกันมาก) · ตัดความถี่แสบหู
- **เซฟอัตโนมัติ** ในเบราว์เซอร์เครื่องนี้ (localStorage)
