# Steelforge Requiem
เกมรถถังมุมมองจากด้านบน (v5) เล่นบนเบราว์เซอร์ ไฟล์เดียว ไม่ต้องติดตั้ง

- **โหมด:** Frontline (ยึดโซน 7 จุด), ดวล, ยึดจุด / เดธแมตช์, Infinity (เวฟไม่จำกัด + เลือกบัฟ)
- **โรงประกอบ:** ตัวถัง, ปืน, ออโตโหลด, เกราะ, ERA, APS, ควัน, เรดาร์, จูน, ลูกเรือ, กระสุน, สกิน
- **เล่นได้ทั้ง PC และมือถือ:** คีย์บอร์ด + เมาส์ (ปรับปุ่มเองได้) หรือจอยคู่ + ปุ่มยิง
- **เซฟอัตโนมัติ** ในเบราว์เซอร์เครื่องนี้ (localStorage)

## ปุ่มเริ่มต้น (PC)
`WASD` ขับ · เมาส์ เล็ง/ยิง · `Space` เบรก · `1` `2` `3` เลือกอาวุธ · `R` สลับกระสุน · `Shift` สแกน (กดค้าง) · `Q` ล็อกเป้า · `X` ควัน · `F` ใช้งาน · `M` แผนที่ · `Esc` ออก
