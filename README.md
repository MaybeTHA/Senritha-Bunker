## Senritha OS
A phone OS-style web app (`index.html`): lock screen, home screen, app switcher, Control Center, and Settings, Clock, Calculator, Notes, Calendar and Tips apps. Animations use spring physics and GPU transforms.

Open `index.html` in a phone browser, or host it with GitHub Pages. Add it to your home screen to run full screen.
