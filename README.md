# Senritha-Bunker
Code stuff and random things

## Projects
Each project lives in its own folder. Keep a project's files inside its folder.

**Inside Bunker** (`index.html` at the repo root, code in [`inside-bunker/`](inside-bunker/)) is the personal OS home page that launches every project. When you add a project, add it to `APPS` in `inside-bunker/app.js` too. With GitHub Pages on, it opens at `https://maybetha.github.io/Senritha-Bunker/`.

| Folder | Project |
| --- | --- |
| [`senritha-os/`](senritha-os/) | Phone OS-style web app |
| [`senritha-rhythm/`](senritha-rhythm/) | Senritha's Rhythm: beat visualizer app for your music |
| [`senritha-solaris/`](senritha-solaris/) | Senritha's Solaris X3D: interactive 3D Solar System explorer |
| [`senritha-motorhome/`](senritha-motorhome/) | Senritha's Motorhome 3D: explorable winter motorhome in three.js |

| [`senritha-perf/`](senritha-perf/) | Senritha's Test performance: WebGL2 graphics benchmark |
