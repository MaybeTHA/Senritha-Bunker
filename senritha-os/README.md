# Senritha OS
A phone OS-style web app: lock screen, home screen, app switcher, Control Center, and Settings, Clock, Calculator, Notes, Calendar and Tips apps. Animations use spring physics and GPU transforms.

## Files
- `index.html` – layout
- `style.css` – styles and theme tokens
- `app.js` – spring engine, gestures, window manager and apps

## Run
Open `index.html` in a phone browser, or host this folder with GitHub Pages. Add it to your home screen to run full screen.
